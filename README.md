## 🎯 Project Objective

The objective of this project is to analyze Adventure Works sales data and provide meaningful insights into:

- Overall sales performance
- Total profit and profit margin
- Year-wise sales trends
- Month-wise sales performance
- Quarter-wise sales performance
- Monthly sales and cost trends
- Top profitable products
- Product profitability
- Business performance over time

## 📌 Key KPIs

- **Total Sales:** ₹29,358,677
- **Total Profit:** ₹12,080,884
- **Profit Margin:** 41.15%
